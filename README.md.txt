Retail Sales Performance Analysis

Project Overview

This project analyses retail sales performance using a synthetic retail dataset. The objective is to evaluate revenue, profit, units sold, and order performance while identifying useful business insights.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Excel Slicers
- Data Cleaning and Analysis

Key Performance Indicators (KPIs)

- Total Revenue: $14,230
- Total Profit: $4,899
- Units Sold: 162
- Total Orders: 30

Dashboard Features

- Sales performance overview
- Revenue and profit analysis
- Regional performance analysis
- Product performance analysis
- Interactive Region and Product slicers

Project Objectives

- Understand retail sales performance.
- Monitor key business performance indicators.
- Identify sales trends and performance differences.
- Present findings through an interactive dashboard.

Dataset

The project uses a synthetic retail sales dataset for learning and demonstration purposes.

Project Status

Excel analysis and dashboard completed.
